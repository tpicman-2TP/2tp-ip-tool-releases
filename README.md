# 2TP Visuals IP Tool – downloads

Fast switching of network adapter IP settings for shows: presets for every LAN port and Wi-Fi, profiles that set several adapters at once, network load per adapter and a Quick switch view with big buttons.

**Download:** see [Releases](../../releases/latest) – the newest Windows installer (`IP-Tool-Setup-x.y.z.exe`, Windows 10/11, 64-bit) and the macOS version (`IP-Tool-x.y.z-macOS.dmg`, Apple Silicon + Intel).

The app checks this page once a day for a newer version (only the app version is sent) and shows an **Update** button when there is one. Nothing is downloaded or installed by itself.

This repository holds only the installers and release notes – no source code. © 2026 2TP Visuals · [www.2tpvisuals.com](https://www.2tpvisuals.com)
